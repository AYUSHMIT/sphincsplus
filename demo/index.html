What is SPHINCS+?

SPHINCS+ is a stateless hash-based signature scheme selected by NIST as a post-quantum cryptography standard. Unlike RSA and ECDSA, it remains secure against quantum computers.

⚛️

Quantum Threat

Quantum computers running Shor's algorithm can break RSA, ECDSA, and other classical cryptosystems. SPHINCS+ is designed to resist these attacks.

🌳

Hash-Based Security

Security relies only on the collision and preimage resistance of cryptographic hash functions—a minimal and well-understood assumption.

⚙️

Flexible Parameters

Choose between 6 parameter sets offering trade-offs between signature size, signing speed, and security level (128, 192, or 256 bits).

How It Works

  1. Message Hashing: The message is hashed to produce a digest
  2. FORS Signature: A few-time signature is generated for the message
  3. Tree Selection: A path through the hypertree is selected
  4. WOTS+ Signatures: One-time signatures are computed at each layer
  5. Authentication Path: Sibling nodes are collected to verify the path
  6. Final Signature: All components are combined into the signature
